# 🎓 School Website

A responsive and modern **School Website** built using **HTML, CSS, and JavaScript**.
This project represents a complete multi-page school website layout designed with clean UI, reusable components, and responsive design principles.

## ✨ Features

* ✅ Fully Responsive Design
* ✅ Multi-Page Website
* ✅ Reusable UI Components
* ✅ Clean Folder Structure
* ✅ Navigation & Header System
* ✅ News & Events Section
* ✅ Admissions & Learning Pages
* ✅ Optimized Assets Management
